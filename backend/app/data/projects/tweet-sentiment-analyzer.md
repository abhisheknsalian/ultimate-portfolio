# Tweet Sentiment Analyzer

## Project Summary

This project is a Natural Language Processing (NLP) application that classifies tweets as either positive or negative using both a traditional rule-based sentiment analysis approach and a transformer-based language model. The objective was to compare the performance of TextBlob with a pretrained Twitter-specific RoBERTa model while deploying the final application as an interactive web app.

The project demonstrates practical experience in sentiment analysis, transformer models, model evaluation, and machine learning deployment.

---

# Project Overview

Sentiment analysis is one of the most common Natural Language Processing tasks used by businesses to understand customer opinions from social media platforms.

This project compares a lightweight rule-based sentiment analysis model with a transformer model trained on millions of Twitter posts to evaluate their strengths and weaknesses in classifying tweet sentiment.

The final solution was deployed using Streamlit on Hugging Face Spaces, allowing users to analyze tweet sentiment interactively.

---

# Why I Built This Project

I wanted to explore modern Natural Language Processing techniques and understand how transformer models perform compared to traditional sentiment analysis methods.

Instead of using only a pretrained transformer, I compared it against a simple baseline model to better understand the advantages and trade-offs between classical NLP approaches and deep learning models.

---

# Problem Statement

Social media generates millions of opinions every day, making it difficult to manually understand customer sentiment.

The objective of this project was to build an automated sentiment analysis system capable of:

- Classifying tweets as positive or negative
- Comparing traditional and transformer-based NLP approaches
- Evaluating model performance
- Deploying an interactive web application

---

# Machine Learning Models

## TextBlob

TextBlob is a rule-based sentiment analysis library that estimates polarity using predefined lexical rules.

It serves as a lightweight baseline model for comparison.

---

## Twitter RoBERTa

The second model uses a pretrained RoBERTa transformer that was trained on approximately 58 million tweets.

Unlike rule-based approaches, RoBERTa learns contextual representations of language, allowing it to better understand informal text, slang, emojis, abbreviations, and complex sentence structures commonly found on Twitter.

---

# Model Comparison

| Model | Accuracy | Negative F1 Score |
|--------|---------:|------------------:|
| TextBlob | 82% | 0.17 |
| Twitter RoBERTa | 79% | 0.32 |

Although TextBlob achieved slightly higher overall accuracy, the RoBERTa model produced a substantially better F1-score for the negative class, making it more effective at identifying negative sentiment.

This highlights the importance of evaluating multiple performance metrics instead of relying solely on accuracy.
